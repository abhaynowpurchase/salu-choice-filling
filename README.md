# DCH & DNB Paediatrics Choice Sheet

A single-page tool for ordering NEET PG 2026 (MCC) choices for **DCH (NBEMS diploma)** and **DNB Paediatrics**.

- Two tabs: **DCH** (86 options) and **DNB Paediatrics** (92 options)
- Type a preference number (1, 2, 3 …) next to any hospital; each number can be used only once
- Each option shows Open seats (2026 MCC final DNB seat matrix), 2025 last Open rank, chance, monthly stipend and bond
- Filters by state, chance and "no bond only"; copy the numbered list as text
- Your numbers are saved in your own browser (localStorage)

Open `index.html` in any browser, or enable GitHub Pages for this repo.

Data sources: MCC NEET PG 2025 allotment results (Rounds 1–3, Stray), MCC Final DNB Seat Matrix 2026, Meducate DNB stipend and bond tables. Always confirm bond and stipend in MCC's Participating Institute Details before locking choices.
